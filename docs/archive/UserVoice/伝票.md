# 伝票の情報
## 伝票詳細画面の上
伝票が売上の場合、「売上日」「納品日」が必要だ。
- 伝票番号
- 引用元伝票番号（伝票を引用して作った場合に記録する）
- 得意先名
- 案件名
- 取引区分（掛売上・個別請求・現金売上）
- 消費税区分　（明細の記載額（売価）が税抜か、税込か）
- 摘要
- 種別（売上の分析に利用する。アプリ設定で分類を変更可能）
- 売掛ID（請求書発行時、その回の売掛に紐付けられる）
- 請求済チェックマーク
- 請求日

## 伝票詳細画面の明細の下
- お客様への「説明」文章と、
- お客様に見せない「社内情報」文章
- 税抜小計
- 消費税小計
- 値引小計（税込後値引、手動入力）
- 売上金額
- 純利益小計
- 純利益率
- 粗利小計
- 作業日数
- 作業時間小計


# 伝票の所属
得意先 > 案件 > 伝票 という関係になる。
検索の場合もその関係に連動すべき。新規伝票作成の場合も同様。

## 大きく分けて２つ　見積書などで外部に見せるものと見せないもの
	行番号
	取付場所
	名称
	数量
	単価（集計区分ごとの売値）
	集計区分ごとの売価（手動設定だが「原価から設定」ボタンで算出）
	合計金額
	備考（２段目１行）

	１個あたりの集計区分ごとの製造原価（手動入力だが建具台帳やカタログシステムから引用可能）
	製造原価合計（集計区分ごとの合計金額）（
	利益（売上ー製造原価）
	利益率
	材料原価（集計区分の労務時間以外の区分の原価の合計額
	粗利率（売値ー材料原価）
	労務単価
	日割粗利（アプリ設定に１日あたりの労働時間がある）

	
	原価を引用で入力した場合は、「引用元を追跡できる番号」が記録されていてほしい。クリックしたらそれを開けるようになっていてほしい（建具台帳かカタログシステム）
-
利益率はコンボボックスで、数値入力もできるようにしてほしい。コンボボックスのドロップダウンリストへ表示する内容はアプリ設定で設定可能にしたい。# 伝票 ユーザー要件メモ

## 関係性
得意先 > 案件 > 伝票（見積/売上）という3段階の親子関係。

## 目標UXフロー（例）
1. 得意先一覧 → 「田中建設」をクリック → 得意先詳細
2. 得意先詳細に「この得意先の案件を見る」ボタン
   → 案件一覧（田中建設の案件に絞り込み済み）
3. 案件一覧から「A邸新築工事」をクリック → 案件詳細
4. 案件詳細から「＋見積作成」→ 伝票編集（得意先・案件がプリセット済み）

## 伝票一覧の絞り込み
- 得意先を選ぶと、その得意先の案件だけが案件セレクトに表示される
- 案件を絞ると、その案件の伝票だけ表示
- 両フィルタは独立して使えること（案件なしで得意先だけ絞りもOK）

## 新規伝票作成
- ProjectDetailの「＋見積作成」ボタンから作成すると、得意先・案件が両方プリセットされること
- VoucherListの「＋新規」ボタンから作成するときは、現在のフィルタ状態（得意先・案件）を引き継ぐこと
