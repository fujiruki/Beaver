## 伝票編集画面（VoucherEdit）— 最重要画面

システムで最も複雑な画面。リアクティブ設計の核心。

### レイアウト

```
┌─────────────────────────────────────────────┐
│ VoucherHeader                                │
│ 得意先 | 案件 | 伝票番号 | 日付 | 税方式      │
├─────────────────────────────────────────────┤
│ ProfitRateBar                                │
│ 利益率プリセット（20%/25%/30%/35%/40%）         │
├─────────────────────────────────────────────┤
│ 明細行テーブル                                 │
│ ┌─┬────┬──┬────┬────┬────┬────┬───┐         │
│ │#│品名  │数│原価列…│売価列…│行計 │税区│操作│         │
│ ├─┼────┼──┼────┼────┼────┼────┼───┤         │
│ │1│框戸  │2 │…    │…    │200K│課税│…  │         │
│ │2│ガラス│1 │…    │…    │50K │課税│…  │         │
│ └─┴────┴──┴────┴────┴────┴────┴───┘         │
│ [行追加] [建具台帳から選択] [カタログから選択]    │
├─────────────────────────────────────────────┤
│ TotalSummary                                 │
│ 小計 | 消費税 | 合計 | 粗利 | 粗利率 | 日割粗利 │
├─────────────────────────────────────────────┤
│ [保存] [見積→売上変換] [スナップショット再ロード] │
└─────────────────────────────────────────────┘
```

### 明細行の操作

| 操作 | 説明 |
|---|---|
| 行追加 | 空の明細行を末尾に追加 |
| 建具台帳選択 | TateguSelectorモーダルで建具を選択→原価スナップショット自動ロード |
| カタログ選択 | CatalogItemSelectorでcatalog-systemから検索 |
| 行複製 | 選択行のコピーを直下に挿入 |
| 行挿入 | 空行を選択行の上/下に挿入 |
| 行移動 | ドラッグまたはボタンで上下移動 |
| 行削除 | 明細行を削除 |

### 明細行の列構成（動的集計区分対応）

**原価列（costs）**: 集計区分マスタから動的に生成
- money型: 金額表示（例: 本体、金物、ガラス）
- time型: 時間表示（例: 製作時間、施工時間）

**売価列（prices）**: 同様に動的生成
- time型原価は `merge_into_price_code` で指定された売価列にマージ

**固定列（後方互換）**: cost_body, cost_hardware, cost_glass, cost_factory_hours, cost_site_hours, cost_labor_rate

### リアクティブフロー

```
建具台帳選択 → 原価スナップショットロード → costsフィールド更新
    ↓
watch(costs/prices変更) → 製造原価再計算 → 粗利再計算
    ↓
TotalSummary → 小計・消費税・合計・粗利率をリアルタイム表示
    ↓
保存 → PUT /vouchers/{id} + PUT /lines/{lineId}
```

## 建具台帳詳細画面（TateguItemDetail）

### 構成
- 基本情報（品番・名前・仕様・メモ）
- 固定原価列（本体・金物・ガラス・製作時間・施工時間・時給）
- 追加工程テーブル（catalog-systemまたは手動入力）
- 集計区分別原価内訳（CostBreakdownPanel）
- 使用履歴（この建具を使った伝票明細の直近50件）

## 請求書詳細画面（InvoiceDetail）

### 構成
- 請求ヘッダー（請求番号・得意先・請求日・締日）
- 金額サマリー（繰越 + 売上合計 + 税 − 入金 = 次回繰越）
- 紐づく伝票一覧
- 入金一覧・入金登録フォーム
