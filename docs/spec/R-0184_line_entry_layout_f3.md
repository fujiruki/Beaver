# R-0184: 見積・売上の明細入力レイアウトを「案F3 詰め版」にする

- 受付: 2026-10-17 藤田晴樹さん決定（dodai-back経由）。「めちゃくちゃいい、これで実装して」
- 決定記録: 別プロジェクトAccessTateguの`docs/wiki/adr/ADR-005_beaver_line_entry_layout.md`（状態: 決定）。検討した案と理由はそちら。この仕様はその「決定」7項目をBeaverの実装に落としたもの
- 見本: 晴樹さんのclaude.aiの非公開ページ`https://claude.ai/artifact/FZBT14QFYPC57RyoQ9E1n7`の「案F3 詰め版」（`project/F4.dc.html`）。下の寸法と色は見本から書き写した
- 状態: 仕様確定

## 背景（ADR-005より）

- 余白が空いていて、関係のある要素どうしが離れている
- 数値・金額が左寄せで、3桁区切りが無い
- 入力欄が全部独立した枠で、どれとどれが一組なのか分からない

## レイアウト

対象: 伝票画面（`VoucherEdit.tsx`）の明細（`LineItemRow.tsx`と、その上の見出し）。見積・売上とも。表（`<table>`の16列）をやめ、1行を次の形にする。

```
[No/選択] [左のまとまり 330px]                [右のまとまり]                                              [利益]
          ┌取付建具（3行まで）──────────┐    [売値      ][本体|金物|ガラス][課税        ] 単価 26,600  金額 79,800   利益 -58,200
          └──────────────────┘    [原価・作業][本体|金物|ガラス][工場h|現場h|労務単価] 労務費 136,800 製造原価 138,000   利益率 -72.9%
          [取付場所 170px|数量 56px] 備考＋                                                                  粗利率 98.5% / 日割粗利
```

1. 明細1行を左右2つのまとまりに分ける
   - 左（幅330px）: 取付建具（`内容`。3行まで表示できる複数行の入力、高さ45px・行の高さ15px）。その下に、取付場所（幅170px、8文字程度）と数量（幅56px）を1つの枠で並べ、その右に「備考 ＋」。備考は押すと開く（入力があるときは開いた状態か、内容が分かる表示にする）
   - 右: 上段＝売値グループ、下段＝原価・作業グループ
     - 売値（緑の帯）: 帯の名前「売値」（幅62px）→ 売値の集計区分（本体／金物／ガラス）を1つの枠に → 課税（1つの枠、幅162px）→ 計算結果「単価 …」（小さく灰色）「金額 …」（太字）
     - 原価・作業（橙の帯）: 帯の名前「原価・作業」→ 原価の集計区分（本体／金物／ガラス）を1つの枠に → 作業（工場h／現場h／労務単価）を1つの枠に → 計算結果「労務費 …」（小さく灰色）「製造原価 …」（太字）
2. 売値と原価の集計区分（本体／金物／ガラス）は縦の列をそろえる（同じ幅）。列の名前は明細の一番上の見出しに1回だけ出し、行の中には名前を書かない。見出しは「取付建具／取付場所・数量・備考」「本体」「金物」「ガラス」「工場h」「現場h」「労務単価」
3. 意味のまとまりは1つの枠を共有する（売値3つ、原価3つ、作業3つ、取付場所と数量）。枠は角丸5px・1px線（#b6bdc6）、枠の中の欄どうしは1px線（#d8dde3）で区切る
4. 入力欄の数値・金額は右寄せ・3桁区切り（入力中も表示は3桁区切り、値は数値のまま保存）。計算結果（単価・金額・労務費・製造原価）は右寄せにせず、入力欄のすぐ右に並べる（計算結果の欄は幅220px程度で左寄せ）。画面の右端へ寄せない
5. 利益のまとまり（幅96px程度、左に細い線）を計算結果のすぐ右に置く: 「利益」（小さな見出し）、利益の金額（太字、マイナスは赤）、「利益率 …%」、「粗利率 …%」、「日割粗利 ¥…/日」。文字の大きさはほかとそろえる（11px程度）。率と日割粗利の定義はR-0183（追補を含む）
6. 縦方向に詰める: 入力欄の高さ20px、欄の中の上下の余白なし（左右6px）。帯の上下の余白は1px程度。行の間は細い線1本（#d0d7de）で区切り、行ごとの角丸の枠や余白は置かない。行の上下の余白は3px程度
7. ウィンドウの幅に合わせて広げない（固定幅で左に寄せる）。狭い画面では横スクロールでよい

色（見本どおり）: 売値の帯の背景 #eef6ee・名前の文字 #2f6f3a、原価・作業の帯の背景 #fdf3e7・名前の文字 #9a5b13、マイナスの数値 #cf222e、全体の文字 12px（Noto Sans JPの指定は不要。既存のフォントのまま）、数字は等幅数字（`font-variant-numeric: tabular-nums`）

## 集計区分の数

本体／金物／ガラス・工場h／現場hは、集計区分マスタ（`aggregation_category_master`の`measure_type` money・time）から今と同じように出す。区分が増減しても、売値と原価の列はそろったまま並ぶこと。

## 残す機能

今の明細でできることはすべて残す:
- 行の追加・削除・▲▼（並べ替え）・複製・挿入（今の操作の場所と動きのまま）
- 行の選択（今の「選択」ラジオ。No の横に小さく置くか、行を押すと選択できる。選択中の行は背景色で分かるようにする）
- 建具台帳からの選択（TateguSelector）
- 「原価から売値を設定」（ProfitRateBar）、労務単価の初期値（R-0174）
- 明細ごとの保存（blurで保存、R-0164・R-0166の直列化・409の扱い）、読み取り専用（請求済み・取消など）のときは入力不可
- 値引行・小計行（line_typeが normal 以外）の表示。通常行と同じ左右の形で、関係ない欄は出さない
- 日割粗利の表示（R-0183）
- 今の明細の「材料原価」の列は、製造原価と労務費から分かるので出さない（ADR-005の決定の形に合わせる）
