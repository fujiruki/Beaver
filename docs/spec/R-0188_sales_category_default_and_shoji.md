# R-0188: 売上種別の既定値を「1地元建具」にし、「5障子張替え」を足す

- 依頼: 2026-10-20 藤田晴樹さん（dodai-back経由。dodai-backのセッションで「そのとおり」と了承）
- 状態: 仕様確定

## 変更

1. 伝票作成画面（`VoucherEdit.tsx`）で新しく作る伝票の売上種別の初期値を、未設定（null）から`1`（「1地元建具」）にする。見積・売上とも（作成画面は共通）。ユーザーは今までどおり変えられ、未設定にも戻せる
2. 既存の伝票の売上種別は変えない（未設定の伝票はそのまま）。編集画面で既存の伝票を開いたときも、保存されている値をそのまま出す
3. APIの既定値は変えない（`POST /vouchers`で指定が無ければNULL、Accessからの同期も送られた値のまま）
4. `sales_categories`に`id=5`「5障子張替え」（sort_order 5、有効）を足す。Accessの`tbl売上種別`もID 5で足す。IDは画面から足さず、id指定のデータ修正で入れる（Accessと同じ番号にするため）

## 反映

- Beaver_beta: コードのデプロイと`id=5`の行追加（退避してから）
- 本番: Access側の改名（dodaikun2026）のあと、dodai-backの合図でAccessと一緒に入れる（コードのデプロイと`id=5`の行追加）

## 受け入れ条件（テスト）

1. 新規作成画面を開くと、売上種別の選択欄が「1地元建具」になっている
2. そのまま保存すると、`POST /vouchers`の`sales_category_id`が1
3. 未設定に変えて保存すると`sales_category_id`がnull
4. 売上種別が未設定の既存の伝票を開くと、未設定のまま表示され、保存しても1にならない
