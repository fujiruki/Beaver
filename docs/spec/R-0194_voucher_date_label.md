# R-0194: 伝票日付の見出しを見積は「見積日」、売上は「売上日」にする

- 依頼: 2026-10-24 藤田晴樹さん（このセッションで直接）。ADR-007のA案（列は`voucher_date`のまま、見出しだけ出し分け）を受けて、晴樹さん「見積では『見積書発行日』がいいって僕が言うたんだけど、『見積日』に変えて。ほんとは前者が的確な表現だけど、3文字にしたほうが画面上ではいいとおもった。そのことも用語集に加えて」
- 状態: 仕様確定
- 用語集: 正本はAccessTategu `docs/spec/07_用語集.md`。「見積日」（見積書を発行した日。画面では3文字に収めるため「見積日」と呼ぶ）の追記をdodai-backに依頼済み

## 変更

- 伝票画面（`VoucherHeader.tsx`）の見出し「伝票日付 *」を、見積は「見積日 *」、売上は「売上日 *」にする
- 伝票一覧（`VoucherList.tsx`）の列名「伝票日付」を、見積の一覧は「見積日」、売上の一覧は「売上日」にする（見積・売上が混ざる一覧なら「伝票日付」のまま）
- 請求書の明細（`InvoiceDetail.tsx`）の「伝票日付」は売上だけなので「売上日」にする
- 列（`voucher_date`）・APIは変えない

## 受け入れ条件（テスト）

1. 見積の伝票画面の見出しが「見積日」、売上は「売上日」
2. 見積の一覧・売上の一覧の列名がそれぞれ「見積日」「売上日」
3. 請求書の明細の列名が「売上日」
