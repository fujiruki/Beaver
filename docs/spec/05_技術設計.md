## 設計パターン

| パターン | 適用箇所 |
|---|---|
| TanStack Query | サーバー状態管理。キャッシュ・楽観的更新 |
| React Hook Form + useFieldArray | 伝票明細行の動的管理 |
| Zustand | AppSettings（利益率プリセット等） |
| 固定列+動的サブテーブル二層構造 | 旧データ互換を保ちつつ新機能対応 |
| 原価スナップショット | 建具選択時点の原価を凍結 |

## コーディング規約

- ページは `src/pages/` に配置
- APIフックは `src/api/{リソース名}.ts`（customers.tsを見本に）
- 型定義は `src/types/{リソース名}.ts`
- 新規計算関数を追加したら必ずテストを書く
- コメント・コミットメッセージは日本語
