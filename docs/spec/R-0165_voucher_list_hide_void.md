# R-0165: 伝票一覧で取消済み（void）を基本は表示しない

- 要望: 2026-10-10 藤田晴樹さん（dodai-back経由）
- 状態: 仕様確定

要望の内容（dodai-back経由）: 伝票一覧では、取消済み（void）を基本的に表示しない。右上あたりに「取消済みも表示」の切り替え（トグル）を置き、オンにしたときだけ出してほしい。

## 仕様

### API（GET /vouchers）

- 新しい指定`exclude_void=1`を追加する。指定されたときは`status <> 'void'`の伝票だけを返す。ページング（件数・ページ数）にも同じ条件を効かせる
- 指定が無いときの動きは今のまま（取消済みも返す）。伝票一覧以外の画面がこのAPIを使っていても影響しない
- `status=void`が指定されたときは`exclude_void`より`status`を優先する（取消済みだけを見る操作を妨げない）

### 伝票一覧（frontend/src/pages/VoucherList.tsx）

- 一覧の右上（検索・絞り込みの並び）に「取消済みも表示」のトグル（チェックボックス）を置く。既定はオフ
- オフのときはAPIに`exclude_void=1`を付ける。オンのときは付けない
- トグルの状態はURLの検索パラメータに持つ（他の絞り込みと同じ。例`include_void=1`）。切り替えたら1ページ目に戻す
- ステータスの絞り込みで「無効」（void）を選んだときは、トグルに関係なく取消済みを表示する

## 受け入れ条件（テスト）

1. `GET /vouchers?exclude_void=1`（ページングあり・なし）は取消済みを返さず、件数・ページ数も取消済みを除いた数になる（PHP）
2. `exclude_void`なしは今と同じく取消済みも返す（PHP）
3. `exclude_void=1&status=void`は取消済みを返す（PHP）
4. 伝票一覧を開くと、APIに`exclude_void=1`が付く（vitest）
5. 「取消済みも表示」をオンにすると`exclude_void`が付かず、URLに`include_void=1`が入り、1ページ目に戻る（vitest）
6. URLに`include_void=1`がある状態で開くと、トグルがオンで表示される（vitest）
7. 既存のテストと回帰スイートが通る
