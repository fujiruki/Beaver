丸数字の説明（画面上の ●1〜●5）

  1. 納期線を越える分は赤い斜線で塗る。上部の「⚠ 納期注意」バッジと連動。「間に合わないから連絡しなさい」の判断がここでできる
  2. バーはドラッグで左右に動かせて、離した瞬間に保存。「これはあとでいいんじゃないか」をその場で反映できる
  3. 未着手の案件は点線の薄いタイル。まだ動かしやすい案件だと一目で分かる
  4. 展示会など社内の制作は琥珀色。「展示会のためにここを空けたい」が色で主張できる
  5. 下の帯は1日ごとの稼働案件数。濃い日は重なり。「次の仕事はここまで無理だね」はこの帯と空きマーカーで答える

色の言語と表示期間

  • 深緑 = お客様の仕事（進行中）
  • 点線 = 未着手（まだ動かせる）
  • 琥珀 = 社内の仕事（展示会など）
  • 赤 = 納期のことだけに使う。赤が見えたら要相談
  • 黄の列 = 今日。開いた瞬間ここが見える

既定は今日の週から8週間。6ヶ月・1年に切り替えると日付の数字が消えて月の線だけになり、バーの文字はしまわれて左の案件名で読む。ズームスライダーはその間を無段階でつなぐ。文字サイズ（A−/A/A＋）は席で見るときは小さく、みんなで囲むときは大きく。
