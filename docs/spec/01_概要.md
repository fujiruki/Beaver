# 01. 概要

## コンセプト

Beaverは建具製造業の**お金の流れ**を管理するシステム。

- 見積書を作って顧客に提示する
- 受注したら売上伝票に変換する
- 月末にまとめて請求書を発行する
- 入金を記録して消し込む

これら一連の業務をWeb上で完結させ、既存のMS Access（AccessTategu）を段階的に置き換える。

## 業務フロー

```
得意先登録 → 案件作成 → 見積伝票作成 → 見積→売上変換
                                          ↓
                              売上伝票（承認まで進める）
                                          ↓
                              請求書作成（複数伝票をまとめて）
                                          ↓
                              入金登録 → 消し込み
```

## ターゲットユーザー

- 藤田建具店の経営者（藤田晴樹）
- 小規模建具製造業の事務担当者

## 用語定義

| 用語 | 定義 |
|---|---|
| **得意先** | 取引先顧客。請求・入金の管理単位 |
| **案件（プロジェクト）** | 1つの現場や受注案件。得意先に紐づく |
| **伝票** | 見積書または売上伝票。見積（estimate）と売上（sales）を同一テーブルで管理 |
| **明細行** | 伝票内の1行。建具1点の原価・売価を記録 |
| **建具台帳** | 品番マスタ。建具の原価情報（材料費・金物費・ガラス費・製作時間・施工時間・時給）を管理 |
| **集計区分** | 原価・売価の内訳カテゴリ（本体/金物/ガラス/製作時間/施工時間など）。catalog-systemから同期 |
| **原価スナップショット** | 建具台帳から伝票明細に値をコピーした時点の原価。後の単価変動に影響されない |
| **掛率（利益率）** | 原価に対する売価の割増率。粗利率30%なら `売価 = 原価 / (1 - 0.30)` |
| **繰越残高** | 前月から持ち越された未入金額 |
| **請求書** | 月次で得意先ごとに発行。複数の売上伝票をまとめる |
| **売上種別** | 伝票の分類（ユーザーが自由に設定可能なマスタ） |
| **AccessTategu** | 既存のMS Accessシステム。段階的にBeaverで置き換え予定 |
| **catalog-system** | 建具カタログ管理の別プロジェクト。集計区分マスタの連携元 |

## 伝票のステータス遷移

```
draft（下書き）→ submitted（提出済み）→ approved（承認済み）→ billed（請求済み）
                                                              ↑
                                                         請求書作成時に自動変更
                     ↘ void（無効化）
```

- draft / submitted / approved: 編集可能
- billed: 読み取り専用
- void: 読み取り専用
