# R-0226: 予定の表をパネルの幅に収める・追加の行をわかりやすくする

- 状態: 本番反映済み（2026-10-30）。ブラウザでの確認は未
- 要望の原文: `docs/requests_log.md` の R-0226
- 関係する仕様: R-0222、R-0225
- 対象: `frontend/src/components/ProjectSchedulesPanel.tsx` のみ。API・段取りの画面は変えない

## 今の問題

1. 製作の行で終了が空のとき、終了の欄の下に「（時間から）」を2行目として出すため、その行だけ高さが変わってずれる
2. 列の幅（w-32・w-36・w-36・w-24・w-12・w-12）とメモ欄の `min-w-48` の合計がパネルの幅を超え、`overflow-x-auto` で横スクロールになる。時間の欄が潰れ、メモ欄がはみ出す
3. 末尾の追加用の行の種類のセレクトの空の選択肢が「空行に入力すると追加」で意味がわかりにくい。種類を選ばずに日付を入れると「見積」で保存され、「その他」との違いもわからない

## 仕様

- **「（時間から）」の2行目をやめる**。製作で開始があり終了が空の行は、終了の欄に `title="空なら時間（無ければ見積の工数）から終了を出します"` を付けるだけにする。行の高さはどの行も同じ
- **横スクロールをなくす**
  - `overflow-x-auto` の箱と `min-w-48` をやめる
  - 表を `table-fixed` にし、列の幅を 種類 w-28・開始 w-36・終了/期限 w-36・時間 w-20・メモ 残り全部・済 w-10・削除 w-10 にする
  - 時間の欄は数値が読めること（右寄せのまま）
- **追加用の行をわかりやすくする**
  - 種類のセレクトの空の選択肢の文言を「＋ 予定を追加（種類を選ぶ）」にする
  - 行の字は薄い字の行と同じ色（`text-slate-400`、セレクトも）
  - 種類を選ばないまま行から出ても保存しない（「見積」にしない）。入れた日付・時間・メモは消さずに残し、種類のセレクトに赤い枠（`border-red-400`）を付けて選ぶよう促す
  - 種類を選んでいて、日付か時間が入っていれば、今までどおり行から出たときに保存する

## 受け入れ条件（vitest、Testing Library）

1. 製作で開始があり終了が空の行に「（時間から）」の文字が出ない
2. 表を包む `overflow-x-auto` が無く、表が `table-fixed`
3. 追加用の行で、種類を選ばず開始日を入れて行から出ても作成の API が呼ばれず、入れた開始日が残る。種類を選んでから行を出ると1回だけ呼ばれ、送る種類が選んだもの
4. 既存のテストと回帰スイートが全部通る
