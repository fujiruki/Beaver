# R-0232 製品台帳の表を Tab・Shift+Tab で区分ごとに続けて入力する

対象: `frontend/src/components/TateguLineItemsPanel.tsx`（材料費の表と工程の表の両方。使う側は製品台帳の画面と、伝票から開く製品台帳のモーダル）

## ねらい

マウスに持ち替えずに、区分ごとの空の行へ次々と入力できるようにする。入力せずに Tab を押せば、次の区分へ進む。

## 決まり

1. **入力中の空の行で、最後の入力欄から Tab**：その行を加え（R-0231 の「行から出たとき」と同じ保存）、すぐ下にできた**同じ区分の新しい空の行の名称の欄**に入る。いまは次の区分の行に入ってしまう。
2. **何も入れていない空の行の名称の欄で Tab**：その行のほかの欄は飛ばし、**次の行の名称の欄**に入る（次の区分の空の行など）。最後の区分なら、表の次の入力欄へ普通に進む。
3. **Shift+Tab は 1・2 の逆**：
   - 行の名称の欄で Shift+Tab を押したとき、ひとつ上の行が何も入れていない空の行なら、その行の**名称の欄**に入る（ほかの欄は飛ばす）。
   - それ以外は、今までどおり1つ前の欄へ戻る。
4. 入力済みの行の中の移動（Tab・Shift+Tab で欄から欄へ）は今のまま。
5. Enter の動きは今回変えない。Enter でフォームが送信されないことは守る。
6. 日本語入力の変換中（`isComposing`）の Tab・Enter は横取りしない。

## 受け入れ条件

- 本体の空の行に「オーデ」「2」「1000」と入れて単価の欄で Tab → 本体の行が1つ増え、フォーカスは新しい本体の空の行の名称の欄にある（材料費・工程の両方）。
- 何も入れていない本体の空の行の名称の欄で Tab → 金物の空の行の名称の欄に入る。
- 金物の空の行の名称の欄で Shift+Tab → 本体の空の行の名称の欄に入る。
- 保存の仕方・API・DB は変えない。

## R-0234 労務費明細を材料費明細にそろえる

- 確かめた今の作り: 労務費も区分（工場時間・現場時間）ごとに空の行が出る（R-0231）。違いは列の並びで、材料費は「区分・名称・数量・単価・金額・削除」、労務費は「工程名・区分・工数・労務単価・金額・削除」。
- 労務費の列を「区分・工程名・工数・労務単価・金額・削除」にし、列の幅も材料費とそろえる。空の行の区分名の出し方も材料費と同じにする。
- 上の R-0232 の Tab・Shift+Tab の決まりは、労務費でも同じに動く（「名称の欄」は工程名の欄）。
- 受け入れ条件: 労務費の表の1列目の見出しが「区分」、2列目が「工程名」。工場時間の空の行で工程名・工数・単価を入れて単価の欄で Tab → 工場時間の行が1つ増え、新しい工場時間の空の行の工程名の欄に入る。
