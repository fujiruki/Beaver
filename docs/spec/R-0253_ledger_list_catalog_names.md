# R-0253 製品台帳の一覧で、入っているカタログの名前を出す

原文は requests_log の R-0253。R-0252 その1（カタログ）の続き。

## 画面（`TateguItemList.tsx` の各行の「カタログに追加▼」）
- 台帳がどのカタログにも入っていなければ、今のまま「カタログに追加▼」。
- 1つ以上のカタログに入っていれば、ボタンの文字をカタログ名にする（例「障子カタログ▼」）。2つ以上なら名前を「、」でつなぐ。ボタンの幅に入らない分は省略記号（…）で切り、マウスを乗せると全部の名前が title に出る。
- 入っている行のボタンは、入っていない行と見分けがつくよう、文字を通常の濃さにする（入っていない行は今の沈んだ見た目のまま）。新しい色は作らない（DESIGN_SYSTEM の文字の濃さ3段の範囲）。
- メニューを開くと、入っているカタログには ✓ を付ける。✓ の付いたカタログを押すと、そのカタログから外す（入っていないカタログを押すと今どおり追加）。
- ボタンには type="button"。

## API
- `GET /tategu-items` の各台帳に `catalog_names`（そのカタログの順＝`ledger_catalogs.sort_order` の配列）と `catalog_ids` を足す。1回の問い合わせでまとめて取る（台帳ごとに問い合わせない）。
- 外す: 既存の `PUT /ledger-catalogs/{id}/items`（全件入れ替え）で、その台帳を除いた並びを送る。新しい窓口は作らない。
- 同期の返り値（`tateguSyncRow`）には出さない。台帳の `updated_at` は進めない（R-0252 と同じ）。

## 受け入れ条件
- カタログに入っていない台帳は「カタログに追加▼」、入っている台帳はカタログ名、2つならつないだ名前が出る（vitest）。
- メニューで ✓ のカタログを押すと外れ、ボタンが「カタログに追加▼」に戻る（vitest）。
- `GET /tategu-items` に catalog_names が順番どおり入り、同期の返り値には入らない（PHP、本物の SQLite）。
- 外しても台帳の updated_at は変わらない（PHP）。
