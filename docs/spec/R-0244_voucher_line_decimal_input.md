# R-0244 伝票の明細の数値欄に小数を入れられるようにする

対象: `frontend/src/components/voucher/LineItemRow.tsx` の `FormattedNumberInput`

## 原因
`onChange` で、打った文字を毎回 `formatNumber(parseNumber(raw))` で表示し直している。「1.」と打った瞬間に `1` と読まれて表示が「1」に戻り、小数点が消える。工場・現場の時間のほか、この部品を使う数値欄すべてで起きる。製品台帳の表（`TateguLineItemsPanel` の `NumericCell`）は別の部品で、小数を受ける。

## 決まり
1. 入力中（フォーカスがある間）は、打った文字をそのまま表示する。小数点・途中の「0」（例「1.0」「0.」）を消さない。
2. 値としては今どおり `parseNumber` で読んだ数を渡す（「1.」は 1、「1.5」は 1.5）。
3. 欄から出たら、今どおり3桁区切りで表示し直す。小数は消さない（`formatNumber` が小数を何桁まで出すかを確かめ、1.5・0.25 が欄から出たあとも 1.5・0.25 と出ること）。
4. 円の欄（売値・単価など）で小数を入れたときの扱いは今のまま変えない（この直しでは整数への丸めを足さない）。

## 受け入れ条件
- 工場時間の欄に「1」「.」「5」と1文字ずつ打つと、表示が「1」→「1.」→「1.5」になり、値は 1.5 で保存される。
- 「0.25」も同じく入り、欄から出たあとも「0.25」と出る。
- 「12,000」のような3桁区切りの表示は、欄から出たときに今どおり出る。
