## 計算ロジック（voucherCalc.ts）

### 製造原価

**固定列方式（後方互換）:**
```
製造原価 = 材料費(cost_body) + 金物費(cost_hardware) + ガラス費(cost_glass)
         + (製作時間(cost_factory_hours) + 施工時間(cost_site_hours)) × 時給(cost_labor_rate)
```

**動的集計区分方式:**
```
材料原価 = Σ(money型コスト) × 数量
労務原価 = Σ(time型コスト) × 時給 × 数量
製造原価 = 材料原価 + 労務原価
```

### 売価計算（利益率から逆算）

```
売価 = ceil(製造原価 / (1 - 利益率))
```

例: 原価70,000円、利益率30% → 売価 = ceil(70,000 / 0.70) = 100,000円

### 伝票合計（税抜/税込対応）

**税抜モード:**
```
課税小計 = Σ(課税明細行のline_total)
消費税  = floor(課税小計 × 税率)
合計    = 課税小計 + 消費税 + 非課税小計 − 値引
```

**税込モード:**
```
税抜金額 = round(税込金額 / (1 + 税率))
消費税   = 税込金額 − 税抜金額
```

### 粗利計算

```
粗利     = Σ(売価 − 製造原価)
粗利率   = 粗利 / 売上合計
総作業時間 = Σ(製作時間 + 施工時間) × 数量
時間あたり利益 = 粗利 / 総作業時間
```

## 見積→売上変換

`POST /vouchers/{id}/convert-to-sales`

- ヘッダー・明細行・costs/pricesサブテーブルをディープコピー
- 伝票番号を新規採番（E00001 → S00001）
- source_voucher_id, source_estimate_no で元見積と関連付け
- 新伝票のステータスはdraft

## 原価スナップショット

- 明細行に建具台帳を選択すると、その時点の原価を明細行にコピー
- 建具台帳の単価が後から変わっても、伝票の原価は変わらない（スナップショット）
- 「スナップショット再ロード」で最新の建具台帳から再取得可能
