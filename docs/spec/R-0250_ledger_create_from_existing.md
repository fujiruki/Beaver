# R-0250 既存の製品台帳を引用して新しい製品台帳を作る

## 決まり
1. **引用の中身**: 元の台帳の 品名・備考・単位など画面で直せる項目と、材料費の行（区分・名称・数量・単価）・労務費の行（区分・工程名・工数・労務単価）を、並びごと写す。
   - 写さないもの: 製品№（`code` は空。Access が採番する。R-0200 の「Beaver は採番しない」のまま）、Access との同期の状態（`last_synced_at` など）、製品図、使用不可（archived）の状態。
   - Access の木材原価計算から来た行（`source = 'wood_calc'`、Beaver で直せない行）は、手入力の行（`source = 'manual'`）として写す（新しい台帳では直せるようにする）。
   - 品名は元のままにし、保存するまで DB には何も作らない。
2. **製品台帳の一覧**（`pages/TateguItemList.tsx`）: 各行の「編集」の横に「引用」ボタン。押すと、引用した中身が入った新規の台帳の画面（`/tategu/new`）が開く。保存すると新しい台帳ができる（元の台帳は変わらない）。
3. **伝票から開く製品台帳**（`components/voucher/ProductLedgerModal.tsx`、作る側）: 新しく作るときに「既存の台帳から引用」を出し、品番・品名で検索して1件選ぶと、その中身が入る。そこから直して「保存して明細へ反映」すると、新しい台帳ができてその明細にひもづく（R-0200(B) と同じ）。
4. 引用した直後は、見出しの近くに「（引用元 製品№ ○○○○○）」と小さく出す（保存するまで）。

## 受け入れ条件
- 一覧の「引用」で新規の画面が開き、品名・備考・材料・工程が元と同じ。製品№は空。保存すると新しい台帳が1件増え、元の台帳は変わらない。
- 木材原価計算の行は、新しい台帳では直せる行になっている。
- 伝票から開く台帳で、検索して引用→保存すると、新しい台帳ができて明細にひもづき、明細の原価が新しい台帳の原価になる。
- API と DB は変えない（新規作成の今の窓口を使う）。
