# R-0248 一覧の画面を開いたら、検索欄にカーソルを置く

対象: `frontend/src/pages/CustomerList.tsx`・`ProjectList.tsx`・`VoucherList.tsx`（見積・売上は `voucher_type` で切り替え、key で作り直している）・`TateguItemList.tsx`（製品台帳）・`InvoiceList.tsx`

## 決まり
1. 上の5つの一覧の画面を開いたとき、検索の文字入力欄にフォーカスを置く。そのまま文字を打てば検索できる。
2. 見積と売上を切り替えたとき（`voucher_type` が変わって作り直されたとき）も、検索欄にフォーカスを置く。
3. ブラウザの「戻る」で一覧に戻ったときも同じ。前に入れていた検索語があれば、その語を選択した状態でもかまわない（打てば置き換わる）。
4. フォーカスを置くだけで、画面のスクロール位置は動かさない（`preventScroll`）。
5. 一覧の中のほかの操作（行のクリック、絞り込みのボタン）は今のまま。

## 受け入れ条件
- 5つの画面それぞれで、開いた直後の `document.activeElement` が検索欄。
- 見積→売上に切り替えたあとも検索欄。
