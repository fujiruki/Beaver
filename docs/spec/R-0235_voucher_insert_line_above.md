# R-0235 伝票の「行を挿入」を、選んでいる行の上に入れる

対象: `frontend/src/pages/VoucherEdit.tsx` の `handleInsertLine`

## 確かめた今の動き
行を選んでいても、いつも伝票の最後に入る。新規作成は `append`、保存済みは `POST /vouchers/{id}/lines` で、サーバーが `MAX(line_no)+1` を振るため。

## 決まり
1. 行を選んでいるとき、「行を挿入」は**選んでいる行の上**に空の行を入れる。選んでいた行から下は1つずつ下がる。
2. 入れたあとは、**新しい行を選んだ状態**にする（そのまま入力できる）。
3. 行を選んでいないときは、今までどおり最後に入れる。
4. 新規作成（未保存）は、フォームの配列の該当位置に入れ、`line_no` を1から振り直す。
5. 保存済みの伝票は、今の `POST` で行を作ったあと、新しい行と、下がった行の `line_no` を、上下移動（`handleMoveUp`/`handleMoveDown`）と同じ `saveLine` で保存する。サーバーの API は変えない。
6. 「行を複製」「行を追加」は変えない。

## 受け入れ条件
- 新規作成で3行あり2行目を選んで「行を挿入」→ 新しい行が2行目、元の2・3行目が3・4行目、`line_no` が 1〜4。新しい行が選ばれている。
- 保存済みの伝票で同じ操作 → 新しい行の POST のあと、新しい行に `line_no: 2`、元の2・3行目に `3`・`4` が保存される。画面の並びも同じ。
- 選んでいないときは最後に入る（今のテストを保つ）。
