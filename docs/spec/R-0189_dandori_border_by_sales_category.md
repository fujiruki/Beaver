# R-0189: 段取りボードのバーの枠線の色を売上種別で分ける

- 依頼: 2026-10-21 藤田晴樹さん（このセッションで直接）「段取りの画面で、種別によって色をわけてほしいな枠線をわけるのがいいかな」→種別は売上種別、色は「県外組子は紫 地元建具 青 障子張替え白 地元組子 水色」
- 状態: 仕様確定

## 案件の売上種別

案件そのものは売上種別を持たないので、案件に付いている伝票から決める。

- その案件の伝票のうち、voidでなく`sales_category_id`があるものの中で、いちばん新しいもの（`voucher_date`の新しい順、同じなら`id`の大きい順）の`sales_category_id`
- 該当する伝票が無ければ未設定
- 2026-10-21時点の本番では、種別の違う伝票を持つ案件は0件
- 段取りボードが使う案件一覧のAPI（`useProjects`が呼ぶ`GET /projects`）の各案件に`sales_category_id`（数値またはnull）を足す。ほかの項目は変えない

## 色

| 売上種別 | 枠線の色 |
|---|---|
| 1地元建具 | 青 `#2563eb` |
| 2地元組子 | 水色 `#38bdf8` |
| 3県外組子 | 紫 `#8b5cf6` |
| 5障子張替え | 白 `#ffffff`（背景に溶けないよう、外側に灰色の細い線 `#94a3b8` 1pxを足す） |
| 4小物・未設定・そのほか | 今のまま（色を付けない） |

- 枠線は3px。今の線の種類は保つ（未着手＝点線、着手中＝実線）。塗りの色（工場／現場、未着手の淡い色、完了の灰色）は変えない
- 未着手のバーは今も点線の枠を持つので、その枠の色を売上種別の色に置き換える（4小物・未設定は今の色のまま）
- 色の割り当ては1か所（定数）にまとめる

## 受け入れ条件（テスト）

1. 案件一覧APIの各案件に、上の決め方どおりの`sales_category_id`が入る（void・種別なしの伝票は無視、いちばん新しい伝票の種別、伝票が無ければnull）
2. 種別1・2・3・5の案件のバーの枠線の色が表のとおり
3. 種別4・未設定の案件のバーは今と同じ見た目（枠線の色を付けない）
4. 未着手のバーは点線のまま、着手中は実線
