# R-0198: 割り当てモードで未割り当て伝票をクリックすると、その得意先の案件に絞り込む

- 依頼: 2026-10-25 藤田晴樹さん（このセッションで直接）「未割り当て伝票を左クリックで選んだら、その得意先の案件に絞り込まれるようにして」
- 状態: 仕様確定

## 変更

- 割り当てモード（R-0195）の右の伝票カードを1回クリックすると、そのカードが選ばれた状態になり、左の案件一覧がその伝票の得意先の案件だけに絞られる
- 絞り込みは案件一覧にもともとある得意先の絞り込み（URLの`customer_id`、得意先名の表示と解除）をそのまま使う。新しい絞り込みの仕組みは作らない
- 選ばれたカードは、ほかのカードと見分けられる（枠や背景。今の画面の選択の見せ方に合わせる）
- 同じカードをもう一度クリック、または得意先の絞り込みを解除すると、選択も絞り込みも外れる。別のカードをクリックすると、そちらに切り替わる
- 伝票の得意先が未設定なら、選んでも絞り込まない（案件一覧はそのまま）
- 選んだ伝票を案件に割り当てたら、選択と絞り込みを外す
- ダブルクリック（R-0197の詳細）とドラッグ（R-0195）は今のまま使える。ダブルクリックで詳細を開くときに選択されても構わない
- 案件の検索文字・並べ替えは絞り込みと一緒に効く

## 受け入れ条件（テスト）

1. カードをクリックすると、案件一覧の取得に`customer_id`（その伝票の得意先）が付き、URLにも`customer_id`が入る
2. 選ばれたカードが見分けられる
3. 同じカードをもう一度クリックすると、`customer_id`が外れる。別のカードで切り替わる
4. 得意先が未設定の伝票では絞り込まない
5. 選んだ伝票を割り当てると、選択と絞り込みが外れる
6. ダブルクリックで詳細が開き、ドラッグで割り当てられる（R-0195・R-0197のテストが通る）
