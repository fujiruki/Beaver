### その他マスタ

- **sales_categories**: 売上種別（id, name, code, is_active）
- **aggregation_category_master**: 集計区分（code, name, measure_type, merge_into_price_code）
- **sequences**: 採番管理（key, last_no）
- **tax_rates**: 消費税率マスタ（valid_from, rate）
- **company_settings**: 自社情報（company_name, default_profit_rate, default_labor_rate等）

## API エンドポイント一覧

### 得意先
- `GET /customers` — 一覧（検索・ページネーション）
- `GET /customers/{id}` — 詳細
- `POST /customers` — 作成
- `PUT /customers/{id}` — 更新
- `DELETE /customers/{id}` — 論理削除
- `PATCH /customers/{id}/carry-forward` — 繰越残高修正

### 案件
- `GET /projects` — 一覧
- `GET /projects/{id}` — 詳細（伝票一覧・時間集計含む）
- `POST /projects` — 作成
- `PUT /projects/{id}` — 更新
- `DELETE /projects/{id}` — 削除
- `GET/POST/DELETE /projects/{id}/images` — 画像管理

### 建具台帳
- `GET /tategu-items` — 一覧
- `GET /tategu-items/{id}` — 詳細（追加工程・集計区分・使用履歴含む）
- `POST /tategu-items` — 作成
- `PUT /tategu-items/{id}` — 更新
- `PUT /tategu-items/{id}/cost-breakdown` — 集計区分全件入替
- `POST/PUT/DELETE /tategu-items/{id}/additions/{addId}` — 追加工程

### 伝票
- `GET /vouchers` — 一覧（フィルタ・ページネーション）
- `GET /vouchers/{id}` — 詳細（明細+costs/prices含む）
- `POST /vouchers` — 作成
- `PUT /vouchers/{id}` — 更新
- `DELETE /vouchers/{id}` — 無効化
- `POST /vouchers/{id}/convert-to-sales` — 見積→売上変換
- `POST /vouchers/{id}/reload-snapshots` — スナップショット再ロード
- `GET/POST/PUT/DELETE /vouchers/{id}/lines/{lineId}` — 明細行

### 請求書
- `GET /invoices` — 一覧
- `GET /invoices/{id}` — 詳細
- `POST /invoices` — 作成
- `DELETE /invoices/{id}` — 削除

### 入金
- `GET /payments` — 一覧
- `POST /payments` — 登録
- `DELETE /payments/{id}` — 削除

### マスタ・その他
- `GET/POST/PUT/DELETE /sales-categories` — 売上種別
- `GET /aggregation-categories` — 集計区分一覧
- `POST /aggregation-categories/sync` — catalog-system同期
- `GET /catalog-proxy` — catalog-systemプロキシ
- `GET /health` — ヘルスチェック
