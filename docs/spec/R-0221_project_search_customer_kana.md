# R-0221: 案件の検索で得意先のよみがなも探す

- 状態: 完了・本番反映済み（2026-10-29、ccb462d）
- 要望の原文: `docs/requests_log.md` の R-0221
- 関係する仕様: R-0091（案件の検索を案件コード・案件名・得意先名に広げた）、R-0084（複数語のAND・かなの揺れ）

## 仕様

- 案件の一覧（`GET /projects?q=`）の検索対象に、得意先のよみがな `customers.name_kana` を足す。対象は 案件コード・案件名・得意先名・得意先のよみがな になる
- 探し方は今のまま（`buildMultiColumnSearchClause`。空白で区切った語のAND、ひらがな・カタカナ・半角カナの揺れを吸収）。ひらがなで打ってもカタカナのよみがなに当たる
- よみがなが空の得意先は、今までどおり名前で当たる

## 受け入れ条件

1. 得意先のよみがな（例「フジタ」）の一部をひらがな（「ふじ」）で入れると、その得意先の案件が出る
2. 「よみがなの語＋案件名の語」の複数語でも絞り込める
3. 今までの検索（案件コード・案件名・得意先名）は変わらない
4. 回帰スイートが全部通る
