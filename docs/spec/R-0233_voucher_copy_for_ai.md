# R-0233 伝票を「AI宛にコピー」する

対象: 伝票の新規作成・編集画面（`frontend/src/pages/VoucherEdit.tsx`）

## ねらい

見積・売上の中身を、そのまま AI（チャッピーなど）に貼って相談できるようにする。明細にひもづく製品台帳の中身まで1回でまとめる。

## 決まり

1. 画面上部の操作の並びに「AI宛にコピー」ボタンを置く（`type="button"`）。読み取り専用の伝票でも使える。新規作成で未保存のときは、いま画面にある内容でまとめる。
2. 押すと Markdown を作り、`navigator.clipboard.writeText` でコピーする。成功したら「コピーしました」、失敗したら「コピーできませんでした」と短く出す。
3. Markdown に入れるもの（画面にある値をそのまま。計算は今の `voucherCalc` などを使い、新しく計算し直さない）:
   - **見出し**：伝票の種類（見積／売上）、伝票番号、日付、得意先、案件、摘要、ステータス、税の扱い
   - **明細の表**：No、品名、取付場所、数量、単位、売値の単価・金額、原価、作業時間、利益、備考。値引・小計の行もそのまま
   - **合計**：税抜・消費税・税込、原価合計、利益と利益率、作業時間合計（画面の合計欄に出ているもの）
   - **製品台帳**：明細が製品台帳にひもづいていれば（`tategu_item_id`）、その台帳ごとに1節。製品№・名前・備考、材料費（区分・名称・数量・単価・金額）、工程（名称・工数・時間単価・金額）、原価の合計。同じ台帳を複数の明細が使っていても1回だけ書き、明細の表からは製品№で引けるようにする
4. 台帳の中身は今ある取得 API（製品台帳の詳細）で読む。読めなかった台帳は「（読み込めませんでした）」と書いて、残りはコピーする。
5. 金額は `¥` 付き3桁区切り。空の値の欄は空のまま。

## 受け入れ条件

- 純粋関数（伝票と台帳のデータ → Markdown 文字列）にテストがある：見出し・明細の表・合計・台帳の節が入る、同じ台帳は1回、読めなかった台帳の書き方。
- ボタンを押すと `navigator.clipboard.writeText` がその文字列で呼ばれる。
- API・DB は変えない。
