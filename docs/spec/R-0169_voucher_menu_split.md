# R-0169: 上部メニューの「伝票」タブを「見積」と「売上」に分ける

2026-10-10 藤田晴樹さん要望（dodai-back経由）。

## 仕様
1. 上部メニュー（AppLayout）の「伝票」を「見積」「売上」の2つにする。リンク先はそれぞれ `/vouchers?voucher_type=estimate`、`/vouchers?voucher_type=sales`（伝票一覧の既存の種別フィルタを使う）。
2. 現在の種別に応じて該当タブを選択中の表示にする（`/vouchers/...` の画面で種別が分からないときはどちらも選択中にしなくてよい）。
3. 伝票一覧画面の種別フィルタはそのまま残す。
