# R-0089: 案件編集画面のステータスをステッパーUIに変更

## 背景

R-0080フィードバック（id=8、2026-08-05 04:48）より。

> 案件編集画面のステータスは横棒に点々と●がある感じで進捗順に並んでるのをチェック入れるほうが直感的で操作しやすいなとおもう。どんなUIがいいかな？

## 対象

`frontend/src/pages/ProjectDetail.tsx` のステータス欄（現状 `<select>{...}</select>`、166-172行目付近）。

## UI設計

`useProjectStatuses()`（`is_active`のみ、`sort_order`順）を横一列のステッパーとして表示する。

- 各ステータスを1つの円（●、`button`要素）として、水平の線でつないで並べる（`display: flex`、円と円の間を`flex: 1`の線で埋める簡易実装でよい）
- 現在選択中のステータスの円は塗りつぶし色（青系）、それ以外は輪郭のみのグレー
- 各円の下（または上）に、ステータス名を小さい文字で表示する
- 円をクリックすると、そのステータスへ即座に切り替わる（`setValue('status', name)`。既存の`<select>`と同じreact-hook-formのフィールドに値をセットする、シーケンシャルな制約（前のステータスを経由しないと選べない等）は設けず、どの円も自由にクリックして選べるようにする）
- アクセシビリティ: 各円は`<button type="button" aria-pressed={...} aria-label={ステータス名}>`にする

## 受け入れ条件

1. ステータス欄が横並びの円＋線のステッパーで表示され、`project_statuses`の`sort_order`順に並ぶこと
2. 現在のステータスの円が視覚的に区別できること
3. 任意の円をクリックするとそのステータスに変更され、保存時に反映されること
4. 既存の`<select>`ベースのテスト（あれば）をステッパーの操作に合わせて更新すること
5. `npm run build`が通ること
