# R-0081 / R-0082: フィードバックモーダルの視認性修正・クリップボード貼り付け

## 背景

R-0080（改善要望フィードバックフォーム）を本番リリースした直後、実際にフォームから届いた要望（2026-08-05、`GET /admin/feedback` id=3）に、フォーム自体への指摘が含まれていた。

> フィードバックモーダル内の入力文字・タイトル・キャンセルボタンの文字が薄すぎて読めない。画像を追加の横に、クリップボードを貼り付けて送るボタンも欲しい。

対象コンポーネント: `frontend/src/components/feedback/FeedbackModal.tsx`

## R-0081: 視認性（文字コントラスト）修正

現状、`<textarea>`・`<h2>`タイトル・「キャンセル」ボタンに明示的な文字色クラスが指定されていない（`FeedbackModal.tsx:106-112`, `92`, `156-161`）。何らかのグローバルスタイルの影響で薄いグレーに見えているため、以下へ明示的に濃い色を指定する。

- `<textarea>`: `text-slate-900`
- `<h2>`タイトル: `text-slate-900`
- 「キャンセル」ボタン: `text-slate-700` 程度の明示色を追加

既存の他ボタン（「＋ 画像を追加」`text-blue-700`、「送信」`text-white`）は元々コントラストが取れているため変更不要。

### 受け入れ条件
- 上記3箇所の文字がbg-white上で明確に読めるコントラストになること
- 既存のvitestテスト（`FeedbackModal.test.tsx`）が引き続き通過すること

## R-0082: クリップボード画像貼り付けボタン

「＋ 画像を追加」ボタンの隣に「📋 貼り付け」ボタンを追加する。

- クリック時 `navigator.clipboard.read()` でクリップボードの画像を取得し、`images`（Fileの配列）に追加する（既存の`MAX_IMAGES=5`上限・重複時のエラーメッセージ処理を流用）
- クリップボードに画像が無い場合、または `navigator.clipboard.read` が使えないブラウザの場合はエラーメッセージを表示する（「クリップボードに画像がありません」等）
- 併せて、`<textarea>` に `onPaste` ハンドラを追加し、Ctrl+V による直接貼り付け（`clipboardData.items`から画像を検出）でも同様に画像を追加できるようにする（ボタンが使えない環境への保険、必須ではないが低コストなので実施）

### 受け入れ条件
- 「📋 貼り付け」ボタンでクリップボード内の画像が添付され、プレビュー・削除が既存の画像と同様に機能すること
- クリップボードに画像がない場合はエラーメッセージが表示され、既存の添付画像・入力内容が消えないこと
- vitestで、クリップボードAPIをモックしたテストケースを追加すること

## 非スコープ
- ドラッグ&ドロップでの画像添付は今回やらない
