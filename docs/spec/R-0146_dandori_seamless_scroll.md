# R-0146: 段取りボードのカレンダーをシームレススクロールで先まで見られるようにする

## 背景

本番フィードバック（`docs/requests.md` 旧§33、id=48、2026-09-06、`/dandori`）:

> 「段取りのカレンダーで右にスクロールしたら10/18より右にいけない。シームレスに読み込みスクロールさせてほしい」

## 原因（調査済み）

段取りボード（`DandoriBoard.tsx`）の表示期間は`rangeForPreset(todayISO, preset)`（`dandoriBoardUtils.ts`）で「8週間」「6ヶ月」「1年」いずれかのプリセットに基づき固定の`start`〜`end`が算出され、`GanttScroll`はその範囲ぶんの幅の要素しか描画しない。横スクロールしても描画済みの範囲の右端で止まり、それより先の日付は存在しない（プリセットボタンで表示期間そのものを切り替えるしかない）。

## 対応方針

`GanttScroll`のスクロールコンテナ（`.gantt-scroll`）に`onScroll`ハンドラを追加し、スクロール位置が右端に近づいたら（残り幅が一定px未満）親（`DandoriBoard.tsx`）へ通知するコールバックを呼ぶ。`DandoriBoard.tsx`はその通知を受けて表示終了日を延長する（プリセットが決める終了日に「延長日数」を加算した値を実際の`rangeEnd`として使う）。プリセット切替時は延長日数を0にリセットする。無制限に伸び続けないよう延長の上限（例: 元の終了日から+2年）を設ける。

### 実装要点

- `dandoriBoardUtils.ts`の`addDaysISO`を`DandoriBoard.tsx`から利用し、`rangeEnd = addDaysISO(presetRangeEnd, extraDays)`という形にする
- `extraDays`は`useState(0)`、`handlePreset()`実行時に0へリセット
- 右端接近の判定・延長量は既存のコードスタイルに合わせた簡潔な実装でよい（例: 残りが400px未満で28日ずつ延長、上限730日）。ズーム（`pxPerDay`）や「折り返し」モードとの組み合わせも問題なく動くこと（折り返しモードはスクロールコンテナが別物のため対象外でよい、横スクロールモードのみ対応）

## TDD

- `dandoriBoardUtils.ts`または新規ヘルパー関数として、「現在のrangeEndと延長日数から実際の表示終了日を計算する」「上限を超えて延長しない」ロジックを純関数化し、vitestで固定する
- `GanttScroll`の`onScroll`→コールバック発火条件（残り幅が閾値未満で発火、閾値以上では発火しない）もテストする

## 受け入れ条件

1. 横スクロールモードで右端付近までスクロールすると、表示期間が自動的に延長され、その先の日付・案件バーが見えるようになる
2. プリセット（8週間/6ヶ月/1年）を切り替えると、延長分はリセットされ元のプリセット幅に戻る
3. 延長には上限があり、無制限に伸び続けない
4. 既存テスト・回帰スイートが通る
