# R-0197: 割り当てモードの右の伝票をダブルクリックで詳細を右の引き出しで開く

- 依頼: 2026-10-25 藤田晴樹さん（dodai-back経由で転送）「この画面で右の伝票をダブルクリックしたらその伝票の詳細がモーダルで開いてほしいな」「あ、画面のUI配置などについてカンガルーのデザイン手順書をみて」
- デザイン: カンガルー「一流デザイン手順書2026」のUI/UX手順で、Codexが2案と実寸モックを作成（`docs/design/R-0197_voucher_detail_modal.md`・`_mock.html`）。晴樹さんが案B（右の引き出し）を選択（backPCのセッションで「案Bいいね」、このセッションで「案Bで作る」）
- 状態: 仕様確定

## Primary Job

右の伝票がどの案件に入るものかを、得意先・摘要・明細の内容から見分ける。左の案件一覧は見えたままにする。

## 表示

- 右の「案件なしの伝票」パネルの上に、右端から引き出しを出す（幅は画面の約半分、モックでは54%）。左の案件一覧は覆わず、読めるまま
- 並び: 伝票番号＋種別（見積／売上）＋状態の印 → 得意先・日付（2列）→ 摘要 → 明細（「全N件」）→ 備考 → 合計
- 明細は1行に品名（太め）と、その下に取付場所・数量（小さめ）、右端に金額。狭い幅のため単価は出さない。多いときは明細の部分だけスクロールし、件数は省略しない
- 原価・利益・同期・内部IDは出さない
- 状態: 読込中（骨組みだけ）、明細0件（「明細はありません」）、void（見出し横に「取消」、本文上部に「取消済みの伝票です」）、請求済み（見出し横に「請求済み」。警告色にしない。案件は変えられるため）、読込失敗（短いエラーと「再試行」）
- 色に頼らず、罫線・文字の大きさ・配置で区別できること
- 下に控えめなリンク「伝票画面で開く」（今のタブで伝票画面へ。戻り先に`/projects?assign=1`を残す）
- 引き出しの中に「割り当て」のボタンは置かない（割り当ては閉じてドラッグ）

## 操作

- 伝票のカードをダブルクリック、またはカードにフォーカスしてEnterで開く
- ドラッグとの両立: 押してから4pxを超えて動いた操作はドラッグとして扱い、ダブルクリックとして開かない
- 閉じる: Esc、×、引き出しの外のクリック。引き出しの中のクリックでは閉じない。閉じたら開いたカードにフォーカスを戻す。右の一覧のスクロール位置と検索条件は保つ
- 開いている間に別のカードを開くことはしない（閉じてから）

## データ

- 既存の`GET /vouchers/{id}`（見出し・明細）を使う。新しいAPIは作らない

## 受け入れ条件（テスト）

1. カードをダブルクリックすると引き出しが開き、伝票番号・種別・得意先・摘要・明細（件数）・合計が出る。左の案件一覧は見えている
2. カードにフォーカスしてEnterでも開く
3. 4pxを超えて動かしたあとのダブルクリックでは開かない
4. Esc・×・外側のクリックで閉じ、カードにフォーカスが戻る。中のクリックでは閉じない
5. void・請求済みの印、明細0件、読込失敗と再試行が出る
6. 「伝票画面で開く」で`/vouchers/{id}`へ移り、戻り先に`assign=1`が残る
7. 原価・利益は出ない
