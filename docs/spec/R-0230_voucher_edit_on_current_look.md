# R-0230 伝票の編集画面：今の見た目のまま、サマリーと入力順だけ変える

晴樹さん（2026-11-09）「元のデザインと見た目が違いすぎる　もとのcssとか見た目そのままつくってくれないと意味がない」。土台は今の伝票画面。
DESIGN_SYSTEM で組み直した見本（docs/design/R-0230_voucher_edit_mock.html、voucherEdit.css）は使わない（参考の配置だけ）。

## 変えないもの
今の画面（`pages/VoucherEdit.tsx`、`components/voucher/VoucherHeader.tsx`・`LineItemRow.tsx`・`TotalSummary.tsx`・`ProfitRateBar.tsx` ほか）の色・文字の大きさ・余白・枠・ボタンの形・インラインスタイル。新しい CSS ファイルや bv- の部品を持ち込まない。今ある機能（説明・非表示記録、製品台帳、原価から売値を設定、AI宛にコピー、自動保存、行操作）もそのまま。

## 変えるもの
1. **サマリーの置き場所**（R-0230 D案、晴樹さん 2026-11-02 の答え）
   - 今は明細の下にある合計・粗利のまとめ（`TotalSummary`）を、明細より上（ヘッダーと利益率の早押しの間）にも出す。中身は、大きく出す6つ＝売上・原価・利益／工場時間・現場時間・合計時間、控えめに出す＝利益率と材料原価の内訳（本体・金物・ガラス等の集計区分）、出さない＝売値の内訳。
   - 画面の幅が明細の幅＋サマリーの幅より広いときは、明細の右にサマリーを置き、スクロールしてもついてくる（sticky）。狭いときは明細の上。
   - 見た目は今の `TotalSummary` の文字・色・枠の作りを使う（新しい色や大きさを作らない。大きく出す6つは、今の画面で一番大きい合計の数字と同じ大きさ）。
   - 明細の下の今のまとめ（税・粗利率・日割り粗利など）は残す。
2. **明細の入力順**（晴樹さん 2026-11-09「取り付け場所、タイトル、数量、備考、原価、売上の順番がいいな」）
   - 明細の左の欄: 1段目に取付場所・品名、2段目に数量・備考（今は品名が1段目、取付場所・数量・備考が2段目）。欄の作り・大きさ・枠は今のまま、並びだけ変える。製品台帳のボタンは品名の横のまま。
   - 右の帯: 原価・作業の帯（橙）を先、売値の帯（緑）を後にする。見出しも同じ順。
   - Tab で進む順も 取付場所→品名→数量→備考→原価→売値。

## 受け入れ条件
- 今の画面と並べて、変えたところ以外の見た目が同じ（色・文字・余白・ボタン）。
- サマリーに6つが大きく、利益率と材料原価の内訳が控えめに出る。売値の内訳は出ない。数字は今の計算（R-0240 の値引き、R-0245 の切り捨て）と一致。
- 幅の広い画面で右、狭い画面で上。
- Tab の順が上のとおり。今のテスト（R-0184 など）が確かめている機能は全部残る。
