# R-0105: 左メニュー下部にビルド時刻を表示

## 背景
藤田晴樹さんより会話内で直接（2026-08-07）:

> 左メニューの下部に、ビルド時刻が表示されるようにできますか？そうすればいつのビルドかわかるので。そしてそれが1日以内と、1時間以内がわかるようにフォント色が変わるようにして

R-0104のデプロイ直後、「まだ直っていない」という指摘を受けたが、実際はブラウザ側がリロードされておらず古いビルドを見ていただけだった。今表示中の画面がどのビルドかを常時可視化し、この種の混乱を防ぎたい。

## 対象
- `frontend/vite.config.ts` — ビルド時刻の注入
- `frontend/src/components/layout/AppLayout.tsx` — サイドバー下部への表示
- 型定義用の`.d.ts`ファイル（新規、置き場所は既存の`src/vite-env.d.ts`があればそれに追記、無ければ新規作成）

## 実装方針

### 1. ビルド時刻の注入
`vite.config.ts`の`define`で、ビルド実行時刻をUTC ISO文字列としてグローバル定数に埋め込む:
```ts
define: {
  __BUILD_TIME__: JSON.stringify(new Date().toISOString()),
}
```
これは`vite build`実行時に評価される値であり、`npm run dev`（開発サーバー）では開発サーバー起動時刻になる（開発時の挙動として許容する）。

TypeScriptのコンパイルを通すため、グローバル型宣言を追加する（例: `declare const __BUILD_TIME__: string;`）。

### 2. サイドバーへの表示
`AppLayout.tsx`のサイドバー（`<nav>`）下部、既存の「改善要望を送る」ボタン（`FeedbackModal`）の下に、ビルド時刻表示を追加する。

- 表示形式: `ビルド: YYYY-MM-DD HH:mm`（JST、`Asia/Tokyo`で明示フォーマット。ビルドを実行するPCのタイムゾーンに依存させない）
- 文字色（経過時間に応じて3段階）:
  - ビルドから**1時間未満**: 目立つ色（例: 緑系 `#4ade80`）
  - ビルドから**1時間以上24時間未満**: 注意色（例: 黄系 `#fbbf24`）
  - ビルドから**24時間以上**: 通常の控えめな色（既存のサイドバーの控えめ文字色 `#94a3b8` に合わせる）
- 経過時間はページを開いている間に閾値をまたぐ可能性があるため、一定間隔（例: 1分ごと）で再評価し、色が自動更新されるようにする（`setInterval`等）。ページ再読み込みしないと色が変わらない、という状態は避ける

## TDD必須
- 経過時間から表示色を決定するロジックは純粋関数として切り出し（例: `getBuildTimeColor(buildTime: Date, now: Date): string`）、以下をテストする:
  - 経過30分 → 1時間未満の色
  - 経過2時間 → 1時間以上24時間未満の色
  - 経過25時間 → 24時間以上の色
  - 境界値（ちょうど1時間、ちょうど24時間）の扱いを明確にしテストする（「未満」「以上」の境界を仕様通りに実装しているか）
- `AppLayout`のレンダリングテストで、ビルド時刻の表示文字列が存在すること（`__BUILD_TIME__`をテスト環境でモック/定義する必要がある。Vitestの`define`設定またはテストファイル内でのグローバル定義で対応）

## 受け入れ条件
1. 左メニュー下部に「ビルド: YYYY-MM-DD HH:mm」の形式でビルド時刻（JST）が表示される
2. デプロイ直後（1時間未満）は目立つ色、1日以内は注意色、それ以降は通常色で表示される
3. ページを開いたまま時間が経過すると、リロードなしで色が自動的に変化する
4. `npm run dev`（開発サーバー）でも起動時刻が表示され、エラーにならない
5. 既存のテスト・ビルド・回帰スイートが通る
