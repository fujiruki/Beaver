# R-0223: 段取りの画面を前後に際限なくスクロールできるようにする

- 状態: 仕様化済み（2026-10-29）
- 要望の原文: `docs/requests_log.md` の R-0223
- 関係する仕様: R-0146（右へのシームレスな延長）、R-0219（左への延長）

## 原因

`frontend/src/pages/DandoriBoard.tsx` の `EXTRA_MAX_DAYS = 730` で、右への延長（`extraDays`）と左への延長（`extraBeforeDays`）がそれぞれ約2年で止まる。

## 仕様

- 左右とも上限をなくす。端に近づくたびに28日ずつ足す今の作り（`EXTRA_STEP_DAYS`）はそのまま
- 左へ足したときに見ている位置が飛ばないこと（R-0219 のスクロール位置の保持）は今のまま
- プリセットを押したら延長を0に戻すのも今のまま

## 受け入れ条件

1. 左右どちらにも、2年を超えて続けて延ばせる（純粋関数のテストで、上限で止まらないことを確かめる）
2. 回帰スイートが全部通る
