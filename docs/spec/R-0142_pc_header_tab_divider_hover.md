# R-0142: PCヘッダーのタブに区切り線とホバーアニメーションを追加

作成日: 2026-09-06　状態: 仕様化済み・着手可

## 背景

本番フィードバックid=47（2026-09-04、`/contents/Beaver`）原文:

> 「上部メニューのタブ、タブごとの区切り線が常にうっすらあってほしいのと、マウスオーバーしたときにクリックできそうな小さなアニメーションを追加してほしい」

R-0139で追加したPCヘッダーのタブナビゲーション（`frontend/src/components/layout/AppLayout.tsx` 73〜121行目）に対する見た目の追加要望。

## 仕様

対象は `AppLayout.tsx` のPC向け `<header>` 内 `<nav>`（`hidden md:flex` の方。モバイル側のハンバーガーメニューは対象外）。

### 1. タブ間の区切り線
- 各タブ（`NavLink`）の間に、常時薄く見える縦線を1本ずつ表示する（最後のタブの右には表示しない）
- 色は背景（`#1e293b`）より少し明るい薄めのグレー系（例: `rgba(255,255,255,0.12)` 相当）とし、目立ちすぎないこと
- 線の高さはタブの文字部分より少し短い程度（タブ全体の高さいっぱいに伸ばさない）

### 2. ホバーアニメーション
- 非アクティブなタブにマウスオーバーした時、背景色が滑らかに変化する（クリックできる要素だと分かる程度の控えめな変化）
- アクティブなタブ（現在の背景色 `#334155`）にはホバー効果を追加しない（既に強調表示されているため）
- トランジションは短時間（150ms程度）で、派手すぎないこと

### 3. 実装上の注意（R-0137の教訓）
`NavLink` の `background` を常にインラインstyleで指定していると（現状 `background: active ? '#334155' : 'transparent'`）、CSSの `:hover` 疑似クラスやTailwindの `hover:` クラスは**インラインstyleに常に負ける**ため効かない。非アクティブ時は `background` をインラインstyleで指定せず（`undefined`にする等）、ホバー時の背景色・トランジションはCSSクラス（Tailwindの `hover:bg-*` `transition-colors` 等、または新規CSSクラス）側に持たせること。
