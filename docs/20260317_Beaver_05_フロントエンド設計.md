## 3. リアクティブ設計の中心：VoucherEdit 画面

見積・売上編集画面は最も複雑なリアクティブチェーンを持つ。

### 3-1. 状態の流れ

```
【サーバー状態 - TanStack Query】
  useVoucher(id) → voucher（ヘッダー + lines[]）
  useTateguItems() → 建具台帳一覧（選択モーダル用）

【クライアント状態 - React Hook Form + Zustand】
  VoucherHeader フォーム
    └─ tax_input_type 変更
         ↓ watch()
         TotalSummary が即座に再計算

  lines[] フォーム（useFieldArray）
    └─ tategu_item_id 変更
         ↓ useEffect
         [1] API: GET /tategu-items/{id} でスナップショット取得
         [2] setValue(cost_body, cost_hardware, ...) で原価フィールド更新
         ↓ watch(['cost_body', 'cost_hardware', 'cost_glass', 'cost_factory_hours', 'cost_site_hours', 'cost_labor_rate'])
         製造原価 = cost_body + cost_hardware + cost_glass
                   + (cost_factory_hours + cost_site_hours) × cost_labor_rate
         ↓ リアルタイム表示（保存前でも見える）

    └─ line_total 変更（手入力）
         ↓ watch(lines[].line_total)
         TotalSummary が即座に再計算（小計・消費税・合計）

【「原価から売値を設定」ボタン】
  profit_rate（Zustandで保持）
  → price = 製造原価 ÷ (1 - profit_rate)
  → setValue(price_body, price_hardware, price_glass, line_total) を全行に適用
```

### 3-2. TotalSummary のリアクティブ計算

```typescript
// hooks/useTaxCalc.ts
export function useTotalCalc(lines: VoucherLine[], taxInputType: string, taxRate: number) {
  return useMemo(() => {
    let taxable = 0, nontaxable = 0, discount = 0;
    for (const line of lines) {
      const amt = line.line_total ?? 0;
      if (line.line_type === 'discount') discount += amt;
      else if (line.tax_category === '課税') taxable += amt;
      else nontaxable += amt;
    }
    if (taxInputType === 'inclusive') {
      taxable    = Math.round(taxable    / (1 + taxRate));
      nontaxable = Math.round(nontaxable / (1 + taxRate));
    }
    const taxAmount = Math.floor(taxable * taxRate);
    const total     = taxable + nontaxable - discount + taxAmount;
    return { taxable, nontaxable, discount, taxAmount, total };
  }, [lines, taxInputType, taxRate]);
}
```

### 3-3. 保存戦略（楽観的更新）

```typescript
// api/vouchers.ts
export function useSaveVoucherLine(voucherId: number) {
  const queryClient = useQueryClient();
  return useMutation({
    mutationFn: (line: VoucherLine) => api.put(`/vouchers/${voucherId}/lines/${line.id}`, line),
    onMutate: async (newLine) => {
      // キャッシュを即時更新（ネットワーク待ちなしでUIに反映）
      await queryClient.cancelQueries({ queryKey: ['vouchers', voucherId] });
      const prev = queryClient.getQueryData(['vouchers', voucherId]);
      queryClient.setQueryData(['vouchers', voucherId], (old: Voucher) => ({
        ...old,
        lines: old.lines.map(l => l.id === newLine.id ? newLine : l),
      }));
      return { prev };
    },
    onError: (_err, _line, context) => {
      // 失敗時はロールバック
      queryClient.setQueryData(['vouchers', voucherId], context?.prev);
    },
    onSettled: () => {
      queryClient.invalidateQueries({ queryKey: ['vouchers', voucherId] });
    },
  });
}
```

## 4. APIクライアント設定

```typescript
// api/client.ts
const BASE = import.meta.env.DEV
  ? '/contents/Beaver/api'          // Vite proxy経由（localhost:8003へ転送）
  : '/contents/Beaver/api';         // 本番も同じパス

export const api = {
  get:    (path: string) => fetch(BASE + path).then(r => r.json()),
  post:   (path: string, body: unknown) =>
    fetch(BASE + path, { method: 'POST',   headers: {'Content-Type': 'application/json'}, body: JSON.stringify(body) }).then(r => r.json()),
  put:    (path: string, body: unknown) =>
    fetch(BASE + path, { method: 'PUT',    headers: {'Content-Type': 'application/json'}, body: JSON.stringify(body) }).then(r => r.json()),
  delete: (path: string) =>
    fetch(BASE + path, { method: 'DELETE' }).then(r => r.json()),
};
```
