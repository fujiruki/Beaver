### customers（得意先マスタ）
*Access `tbl得意先M` 参照。`締日`・`繰越残高`・`請求先名`・`敬称区分` などを取り込み。*

```sql
CREATE TABLE customers (
    id                    INTEGER PRIMARY KEY AUTOINCREMENT,
    code                  TEXT(20) UNIQUE,              -- 得意先コード（従来の得意先№）
    name                  TEXT NOT NULL,                -- 名前
    name_kana             TEXT,                         -- 名前カナ
    honorific_type        TEXT(5) DEFAULT '御中',       -- 敬称区分（様/御中/殿/など）
    gender                TEXT(5),                      -- 性別
    postal_code           TEXT(8),                      -- 郵便番号
    address1              TEXT(50),                     -- 住所1
    address2              TEXT(50),                     -- 住所2
    tel                   TEXT(15),                     -- 電話番号
    mobile                TEXT(15),                     -- 携帯電話
    fax                   TEXT(15),                     -- FAX番号
    email                 TEXT(50),                     -- 電子メール
    memo                  TEXT,                         -- 備考
    billing_name          TEXT(50),                     -- 請求先名（請求書に印字する宛名。NULLなら名前を使用）
    billing_date_print    INTEGER NOT NULL DEFAULT 0,   -- 請求日を請求書に印字する (0=しない, 1=する)
    -- 請求サイクル設定
    cutoff_day            INTEGER DEFAULT 31,           -- 締日（15/20/25/31=月末）
    billing_offset_days   INTEGER DEFAULT 15,           -- 締日から何日後が請求日
    payment_due_days      INTEGER DEFAULT 30,           -- 請求日から何日後が支払期限
    -- 残高
    carry_forward_balance REAL NOT NULL DEFAULT 0,      -- 繰越残高（最新値）
    -- 管理
    is_active             INTEGER NOT NULL DEFAULT 1,   -- 使用可能フラグ
    created_at            DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at            DATETIME DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX idx_customers_code ON customers(code);
CREATE INDEX idx_customers_name ON customers(name);
```

```sql
CREATE TABLE vouchers (
    id                    INTEGER PRIMARY KEY AUTOINCREMENT,
    voucher_no            TEXT UNIQUE,                 -- 伝票番号（E00001 / S00001 形式）

                                                       -- 外税/伝票計 / 外税/請求計 / 税込/伝票計 / 税込/請求計
```

## 指定請求日の動作仕様

```
通常フロー:
  vouchers.billing_date = Sime_Max(delivery_date, cutoff_date)
  ※ Sime_Max = 納品日を含む次の締日から billing_offset_days 後

指定請求日フロー:
  vouchers.override_billing_date に日付をセット
  → 請求処理では override_billing_date を使用
  → 通常サイクルの billing_date は変更しない（記録として残す）
  → 請求管理画面の「指定請求日あり」セクションに表示
```

## スナップショット再読み込み仕様

「スナップショット一括再読み込み」ボタン押下時:
1. 伝票内の全 voucher_lines について tategu_item_id を取得
2. 各 tategu_items の最新 cost_* フィールドを取得
3. voucher_lines.cost_* を上書き、snapshot_loaded_at を現在日時に更新
4. 売価フィールド（price_*）は変更しない

## 税計算仕様

### 税抜入力（tax_input_type = 'exclusive'）
- line_total は税抜金額
- 消費税 = line_total × 税率（端数処理: 切り捨て）

### 税込入力（tax_input_type = 'inclusive'）
- line_total は税込金額
- 税抜相当額 = line_total ÷ (1 + 税率)
- 消費税 = line_total - 税抜相当額

### 集計
- subtotal_taxable = SUM(line_total WHERE tax_category='課税')
- tax_amount = FLOOR(subtotal_taxable × 税率)
- total_amount = subtotal_taxable + subtotal_nontaxable - subtotal_discount + tax_amount

## 原価 → 売価 自動計算仕様

```
製造原価 = cost_body + cost_hardware + cost_glass
           + (cost_factory_hours + cost_site_hours) × cost_labor_rate

「原価から売値を設定」ボタン:
  目標売価合計 = 製造原価 ÷ (1 - profit_rate)
  price_body     = ROUND(cost_body    / 製造原価 × 目標売価合計)
  price_hardware = ROUND(cost_hardware / 製造原価 × 目標売価合計)
  price_glass    = ROUND(cost_glass   / 製造原価 × 目標売価合計)
  line_total     = price_body + price_hardware + price_glass
```
