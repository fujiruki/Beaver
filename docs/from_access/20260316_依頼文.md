# 案件
  案件には現場名・得意先・内容とかがあるんだけど、１案件には複数の見積もりと複数の売上伝票があってもおかしくない。なぜなら、見積は再見積もりが繰り返されたり、現場で追加工事が出て追加見積や追加売上伝票が出ることもある。　見積から予定業務時間などを出すには無効になった見積などの判断も必要かもしれないね。

# 見積から売上へ
  見積から売上に引用したら、メインと明細のレコードすべてをコピーして売上伝票にする。売上の明細を編集した途端に提出済みの見積が変更されてはいけないと思う。

  catalog-systemとの接続方式は案Bですね。見積作成時点のスナップショット。ただし、「この見積書の明細にある項目の全スナップショット読み込み直し」ボタンはほしい。見積作成途中でカタログを変更したというときにも読み込みやすいように。

税計算については、明細行ごとじゃなくて伝票ごとです。「この伝票の各行の金額は税込金額で書いたよ」「税抜金額だよ」ということを書きたい。
