## 1. システム概要

**Beaver**（ビーバー）は、藤田建具店向けの製造業向け 見積・売上・請求・案件管理 Web システム。

### 命名理由
- 木材を精密加工してダムを建設する「職人」→ 建具製造業との親和性
- 地道に働き生態系を豊かにする → 誠実・地域貢献のイメージ
- 一度作ったダムが長期間価値を生む → 収益性

## 3. 3層データ構造

```
【Layer 1】catalog-system
    標準部材・モジュール・商品（Material/Module/Product/Service）
    原価・労務時間を持つ

         ↓ base_catalog_item_id で参照

【Layer 2】建具台帳 tategu_items
    オーダーメイド建具のマスターレコード
    catalog標準品 + 特殊加工・追加工程 を組み合わせて登録
    原価を保持し、過去に使用した伝票と売値の履歴が見える

         ↓ tategu_item_id で参照

【Layer 3】見積/売上明細 voucher_lines
    伝票の1行
    建具台帳から選択時点の原価をスナップショットで保存
    その伝票での売値を記録
```

## 4. 技術スタック

| レイヤ | 技術 | 備考 |
|---|---|---|
| フロントエンド | React + TypeScript + Vite | catalog-system と同系統 |
| バックエンド | PHP 8.x | RESTful API |
| DB | SQLite（初期） | DBラッパー経由でMySQL移行容易に |
| 認証 | セッション管理（PHP） | 将来的にJWT検討 |

### DBラッパー方針
```php
// api/Database.php
class Database {
    private static ?PDO $instance = null;

    public static function connect(): PDO {
        if (self::$instance === null) {
            $dsn = DB_TYPE === 'mysql'
                ? 'mysql:host='.DB_HOST.';dbname='.DB_NAME.';charset=utf8mb4'
                : 'sqlite:'.DB_PATH;
            self::$instance = new PDO($dsn, DB_USER, DB_PASS, [
                PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
                PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
            ]);
        }
        return self::$instance;
    }
}
// config.php の DB_TYPE を 'sqlite' → 'mysql' に変えるだけで移行
```
